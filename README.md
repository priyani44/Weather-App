# 🌤️ Weather App

A responsive weather application built with React and Vite that provides real-time weather information.

## 🚀 Live Demo
https://weather-app-three-orpin-32.vercel.app/

## ✨ Features
- Search weather by city
- Real-time temperature display
- Humidity and wind speed details
- Responsive and user-friendly UI

## 🛠️ Tech Stack
- React
- Vite
- CSS
- OpenWeather API
